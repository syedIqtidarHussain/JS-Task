JavaScript Mini Tools

A collection of small interactive utilities built with vanilla JavaScript.

Age to Days Converter

Enter your age in years to see it converted into days.

Hours to Seconds Converter

Enter hours to see the equivalent number of seconds.

Find Next Number

Search for a number inside an array and get the element next to it, or enter a single value to get its next number (integer or float aware).

Name Capitalizer

Type your name in lowercase only. It will be displayed with the first letter capitalised.

BMI Calculator

Enter your weight and height to calculate your Body Mass Index.

Random Array Generator

Generate a random array, then instantly pick its first and last elements.

Live Number Adder

Enter two integers. The result updates automatically as you type, using event handling.
